# Skills

Show languages and tools from the catalog or custom entries as [Shields.io static badges](https://shields.io/badges/static-badge). Pick one badge style for the section (flat, flat-square, plastic, for-the-badge, or social). Each skill can set Simple Icons [logo slugs](https://simpleicons.org/) plus `logoColor`, `logoSize`, `label`, `labelColor`, `color`, and `link`. **URL** wraps the badge in Markdown; `link` is the Shields query param. Empty fields are omitted from the URL; `color` falls back to the active theme.
