# Skills

Show languages and tools from the catalog or custom entries as [Shields.io static badges](https://shields.io/badges/static-badge). Pick one badge style for the section (flat, flat-square, plastic, for-the-badge, or social). Each skill can set Simple Icons [logo slugs](https://simpleicons.org/) plus `logoColor`, `logoSize`, `label`, `labelColor`, and `color`. Empty fields are omitted from the URL; `color` falls back to the active theme.
