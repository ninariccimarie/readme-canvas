# Socials

Links to GitHub, other platforms, or custom URLs as [Shields.io static badges](https://shields.io/badges/static-badge). Pick one badge style for the section. Each item can set Simple Icons [logo slugs](https://simpleicons.org/) plus `logoColor`, `logoSize`, `label`, `labelColor`, `color`, and `link`. **URL** wraps the badge in Markdown (`[badge](url)`); `link` is the Shields query param. Empty fields are omitted; `color` falls back to the active theme.
